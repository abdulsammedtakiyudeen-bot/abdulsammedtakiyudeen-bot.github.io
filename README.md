# The Dark Stain on Today's Society — Website

Complete static website for the book by Abdul Sammed Takiyudeen.

## Included
- Responsive home page
- Book cover
- All 15 chapters for online reading
- Search across the book
- PDF download
- About the author
- Mobile navigation
- SEO/social metadata
- `robots.txt`

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload the files in this folder.
3. Open **Settings → Pages**.
4. Select the `main` branch as the source and save.
5. GitHub Pages will publish the static site.

GitHub Pages can host HTML, CSS and JavaScript files directly from a repository.
